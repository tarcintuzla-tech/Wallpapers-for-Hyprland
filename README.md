# Hyprland Wallpapers

A collection of 100 wallpapers for **Hyprland** desktop setups. Find minimal, aesthetic, dark, nature, and abstract backgrounds to personalize your Linux desktop.

## 📥 Download

Due to the large file size, wallpapers are provided as a ZIP archive through GitHub Releases.

**[Download All Wallpapers](../../releases/latest)**

## 🖥️ Installation

1. Download the ZIP archive.
2. Extract it to your preferred directory.
3. Choose your favorite wallpaper.
4. Set it using your preferred wallpaper utility.

## 📸 Collection

The repository includes 100 wallpapers in various styles and resolutions.
